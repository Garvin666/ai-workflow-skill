## 字段说明

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| 日期 | YYYY-MM-DD | 交付日（非创建日） |
| 入口类型 | 消息 / 正式需求 / Bug | 阶段 0 的入口分型结果 |
| 任务 | 一句话 | 与 plan.yaml 的 `任务` 一致 |
| 交付物 | 路径列表 | 主要交付文件，多个用 `、` 分隔 |
| 验收结论 | 达成 / 部分达成 / 未达成 | 对照阶段 1 验收标准的核验结果；未达成须注明原因 |
| 独立审核 | 通过 / 抽查豁免（理由） | 命中必送三类（高危产出／用户点名／复发触顶）时为送审结论；未命中写 `抽查豁免（<理由>）` |
| 越界授权 | 无 / 已授权：<路径>（<日期>） | 本任务是否访问过工作区根之外；有则记路径与授权时间 |
