**P2（主要）文档给出的 `decide` 用法会产出被自家门禁判 FAIL 的记录**

`SKILL.md` 核心命令行的规范写法为 `checks.py decide <plan> --point … --basis …`（未列 `--choice`），而门禁 `DECISION_KEYS = ("决策点","依据","选择")`（`:74`）把 **选择** 列为必填。实测（在临时目录的 plan 副本上）：
```

回读：{'决策点': '要不要查外部事实', '能力类': '', '依据': '判据', '选择': '', '时间': '…'}

$ python checks.py plan "<tmp>/dec-no-cap.yaml" --base <技能目录>
[FAIL] 决策记录 — 第1项缺 选择
=== 结果：9/10 通过，FAIL=1 ===
```
即：**照文档执行 → 工具写入 → 同一工具的门禁 FAIL**。`--choice` 在 argparse 中为可选（`required` 仅 `--point/--basis`），但门禁强制非空，两侧口径不一致（模块 docstring `:16` 列了 `--choice`，`SKILL.md` 未列）。
