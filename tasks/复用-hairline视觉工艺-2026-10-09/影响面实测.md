## 4. H1 误报的定位、判断与处置（本次主要产出）

**证据**：`pre-narrow` 输出第 3 行 —— 合规样本 01 的 `.spinner{animation:spin 1.2s linear infinite;}` 被判 H1 FAIL。

**判断**：**旋转 / 进度 / 跑马灯用线性是对的**——匀速旋转的物理语义本就是线性。hairline 禁线性，是因为**它自己的**动效都是「离散选择」与「指针跟随」两类；原样套到通用视觉产物上属于**作用域错配（scope mismatch）**——与本仓已记过的 G1/G6/G7/G11 一族同型病。

**处置**（`s3b_narrow_h1.py`，6 项回读断言通过）：

1. 取数侧给每条缓动记录带族标记：`"scope": "animation" if prop.startswith("animation") else "transition"`；
2. 检查器加射程过滤，**默认 `transition`**（只判状态切换族），`animation` 族默认放行；
3. 要收紧须**显式** `params: { scope: all }`（`PARAM_SPEC` 已登记 `("transition", "all")` 两值）；
4. 判据集 note 登记该边界与 G1/G6/G7/G11 同族的说明；
5. 自检夹具同步改判：`animation` + `linear` ⇒ **SKIP**；`scope: all` ⇒ **FAIL**；`scope: all` 下合规样本 ⇒ **PASS**。

**参数活性自证**（防「加了参数但没人吃」的死参数）：同一语料只改 `scope` 一个值即产出两份可 diff 的输出（`1/2` → `2/3`）⇒ 该参数确实进入判定路径，非死代码。见 `s4b.log`。
