## D1 定位与射程

### D1.1 它是什么

`lucasmarkes/hairline` 是一个**等距线稿（isometric line-drawing）组件库**；被拆对象是其仓库内 `skills/hairline-create/` 这一**生成器技能**：**给一个想法，产出「一张」等距线稿图**，交付形态是**单个自包含 HTML**（图形 ＋ 强度滑杆 ＋ 主题切换 ＋ 播放巡游）。

- **A 档（直引）**：`@a2217852:SKILL.md#frontmatter.description` —— "Draws one isometric line figure that answers the pointer, in the style and on the engine of @lucasmarkes/hairline, and hands it over as a single self-contained HTML file."
- **A 档**：`@a2217852:SKILL.md#Hairline: create a figure` 首段 —— 六个 figure 是标尺（bar），`examples/` 里两个是「你将要写的格式」。
- **A 档**：`@a2217852:SKILL.md#Hairline: create a figure` 第 2 段 —— 作者**只写 figure 一个东西**；engine（`kernel.js`）与 page（`bench.html`）是**固定的**，**永不改、永不粘贴其改动副本**。
- **B 档（归纳）**：因此该技能是「**固定引擎 ＋ 可写插件（figure）＋ 固定页面**」的三段结构，作者可动面**只有 figure 一个文件**。
- **A 档**：`@a2217852:bench.html#description 注释` —— bench 是 figure 被展示的页面，它「makes the host and the svg the way the package's mount does」，并**拥有** read-out / slider / theme / 舞台下那行错误。

#### (2) figure 契约（谁提供什么）

- **A 档**：figure 文件末尾调用 `hairline({ name, means, rules, range, tour, mount })`；`@a2217852:validate.mjs#declared` 逐字段校验：`name` 小写字母/数字/连字符（1–31 字符，`[a-z][a-z0-9-]{1,30}`）、`means` ≤140 字符、`rules` 为 1–10 的整数数组、`range` 三值**同向**、必须有 `mount`。
- **A 档**：`@a2217852:bench.html#window.hairline`（L107–160）提供宿主：`HL.inject(document)` → 建 `viewBox="0 0 400 320"` 的 svg → 造 `read` 代理对象（getter/setter，`null` 写回 `""`）→ 把滑杆 0..1 经 `figure.range` **三段线性映射**成 figure 自己的量纲（L112–114）→ 调 `figure.mount({ stage, svg, read }, value)` → 若 figure 没写过读数则兜底为 `"rest"`（L136）。
- **A 档**：`mount` 必须返回 `{ set, destroy }`；`destroy` 用 `disposer()` 收集的 `bag.dispose`（`@a2217852:rules.md#The frame`）。
- **A 档**：单页只能挂一个 figure —— `if (mounted) throw new Error("hairline: one figure per page.")`（`@a2217852:bench.html#window.hairline` L108–109）。

#### (3) 工具体系的能力面（**显式声明了机器判据的边界**）

- `validate.mjs` 头部 22 行注释即**能力清单**：kernel / parse / bench / text / paint / outside / clock / tween / hit / readout / handle / declare / tour / length（**14 项**）。实测：BAD 5 ＋ NEED 5（`handle` 两条）＋ 直推 5 ＝ 12 个独立产出点，另 2 个由 `parse()` / `declared()` 产出 ⇒ **14/14 全部可追**。
- `look.md` 开头一句即边界声明（**A 档直引**）：「The validator reads text. This is what only eyes can check.」⇒ **机器判据不冒充完整验收**，13 项里只有 8/9/12 与 4 的一部分由 `look.mjs` 自动回答，其余靠人看图。
- **B 档**：`look.mjs` 里被量化的「代理量」有 4 个常量（`@a2217852:look.mjs#第 44–53 行`）：`WAIT 1500 / STILL 250 / CAP 5000`（静帧判定）、`SMALL 0.25`（静息构图的画面占比下限，两范例均 36%）、`FAINT 0.37`（答案对缩略图墨迹的改动比例下限，Terrain 74% / Riffle 139% 的一半）、`INKED 24`（「墨」的像素阈值：纸面上灰线距底色 31）。每个常量**都带它据以取值的实测样本**。

**数据流与关键接线（A 档）**：

- `assemble(figure)`（`@a2217852:build.mjs#assemble`）：读 `bench.html`，把 `/*KERNEL*/` 与 `/*FIGURE*/` 两槽**用函数式替换**填入（`.replace("/*KERNEL*/", () => …)`）→ 产出**单文件**页。

### D2.3 一处需要说明但**不构成矛盾**的表面冲突（C 档推断）
