# 任务确认表模板目录（阶段 0 快速通道 / 阶段 1 模板沉淀）

存放各任务类型的「任务确认表」YAML，文件名 = 任务类型（如 `数据分析.yaml`、`选品分析.yaml`）。

## 快速通道规则（SKILL.md 阶段 0 第 4 条）

- 触发任务前先在本目录找同类模板；命中 → 向用户提议"按上次配置开跑"
- 用户确认后跳过追问循环；配置有出入的条目仍逐条确认
- 模板中缓存的查重结论（research 字段）在无重大变化时免重复查重

## 字段说明

| 字段 | 含义 |
| --- | --- |
| goal | 目标：要解决什么 |
| inputs | 输入：文件/数据/来源 |
| deliverables | 交付物：格式/路径/命名 |
| acceptance | 验收标准：怎样算完成 |
| constraints | 边界约束：禁做事项/依赖/时限 |
| research | 缓存的查重结论（项目/决策/日期） |

## 示例

见 `_示例-数据分析.yaml`。更新原则：同类型存在则更新，不新建重复模板。
